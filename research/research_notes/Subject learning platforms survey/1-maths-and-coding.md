# Child-facing AI and adaptive learning platforms for mathematics and coding, Grades 3–8 — scored survey for Cornerstone (Pune)

Scope and method. Survey dated 26 September 2026. Every URL cited below was opened on that date (directly, through the vendor's public help-centre JSON API, or as a downloaded PDF); the date a vendor page itself carries is given where the page shows one. Claims that surfaced only in search-result snippets, or on pages that could not be opened (403/404/JavaScript-only), are not treated as findings — they are listed under **Gaps** and marked "unverified". Beyond the candidates named in the brief, four serious additions were checked: ALEKS (McGraw Hill), ST Math (MIND Education), Sparx Maths (UK) and Countingwell (India, Grades 6–8), plus the Indian coding vendor Tekie (now part of Uolo). Cuemath, Bhanzu and Codingal are live-tutoring services, not adaptive platforms; they are covered for completeness but are structurally unable to meet the decisive criterion (a tutor's class notes are not a per-skill data feed).

## 1. Per-skill data export and integration standards (the decisive criterion)

### Takeaway
Only four candidates document a per-child, per-skill export that a school could actually ingest: Khan Academy (Districts tier only — an "All Skills CSV" with skill name, mastery level, mastery points, learning time and standards codes), IXL (CSV export from every Analytics report, LTI 1.3 grade passback, OneRoster-based rostering), Code.org/CodeAI (CSV with "level-by-level details" per section) and DreamBox (standards-proficiency reports per student, CSV export claimed but not confirmed in the text I could read). No candidate offers xAPI/Caliper or a public progress API; Clever/ClassLink integrations are one-way rostering (SIS → vendor), not data return. Scratch, Synthesis, Math Academy, Cuemath, Bhanzu and Codingal export nothing per skill.

### Inferences
- Rostering standards (Clever, ClassLink/OneRoster) are near-universal but flow SIS → vendor only; none of the maths platforms documents OneRoster Gradebook/Results, xAPI or Caliper for returning results. The only return paths are (a) CSV downloads and (b) LTI 1.3 Assignment and Grade Services grade passback (IXL, Mathspace via Canvas), which returns a score per assignment, not per skill, unless the school assigns one skill per task.
- Khan Academy's export is the richest (mastery level + points + time + standards code per skill) but is gated behind a Districts contract (250-licence minimum, Clever/ClassLink rostering, Khanmigo-for-students US-only). Whether Khan Academy sells Districts to an Indian school is unknown.
- IXL's export is the most accessible for a small school: any report → CSV, with a SmartScore per skill; skill lists are published per class on the India site, so a crosswalk is buildable.
- Code.org's CSV is per lesson/level, not per skill; the school must map levels to its own coding skills. That is feasible because Code.org courses are fixed sequences.
- DreamBox's standards report is a genuine per-standard proficiency view, but "proficiency" means completing every lesson tagged to the standard — a curriculum-coverage metric, not a measured skill.
- Every "AI tutor" platform without export (Synthesis, Math Academy) can only feed the school record by hand.

### Gaps
- Khan Academy free-tier export: the CSV dictionary is for Districts administrators; whether a teacher on a free account can export per-skill data was not confirmed (Khan's help-centre HTML is blocked; one article returned HTTP 401 via the API).
- DreamBox CSV export: search listings say "Most reports ... can be exported into a CSV" and the Standards Report has "Print and Export buttons", but those sentences were not in the article portions I read — unverified.
- Prodigy: a Clever-hosted page reportedly states "Prodigy information cannot be exported to Clever"; not opened — unverified. No CSV export found.
- Matific, Mindspark, Mathspace, Zearn "Export Center", SplashLearn, CodeMonkey, Tynker, CodeCombat: the exact fields of any export were not documented on pages I could open. GitHub pull-request titles suggest CodeCombat has an "Export Progress" CSV; not opened — unverified.
- 1EdTech certified-product directory pages (IXL, Mathspace, ALEKS) render their certification lists by JavaScript ("Checking Active Certifications...") and could not be read; IXL's LTI Advantage claim rests on IXL's own sheet.
- No candidate publishes an xAPI/Caliper or REST progress API on any page opened.

## 2. Child-facing AI: hints or answers, open chat, and the school's off-switch

### Takeaway
Three AI tutors are explicitly constrained to hints: Khanmigo ("never gives you the answer"), Eedi's tutor (Socratic dialogue triggered only after a diagnosed misconception) and Code.org's AI Tutor (Socratic, but it "can also generate code directly" in Web Lab, is US-only and blocked under age 11). Mathspace's Milo is the only maths AI with a documented teacher off-switch per task and teacher-visible transcripts. Tynker Copilot and Code.org's Web Lab tutor generate code outright; Synthesis and Math Academy describe adaptive algorithms rather than chat; IXL, Zearn, DreamBox, Prodigy, SplashLearn, Mindspark, Scratch, CodeMonkey and Kodable show either no student-facing generative AI or only lightly described "AI tutor" features.

### Inferences
- For Cornerstone's Grades 3–6 the only constrained AI a school can switch off per task is Mathspace's Milo; Khanmigo's controls are at district level and its student access is US-only, so in India Khan Academy is effectively AI-free for students unless a parent buys the $4/month plan at home.

- Tynker Copilot and Code.org Web Lab generate finished code; under the brief's rule ("hints only") they count against those platforms for primary-age use.
- Where a vendor offers "hints" from a database written by humans (Mathspace's ~900,000 hints, per its help pages), the hint layer is verifiable; LLM hints are not.

### Gaps
- Whether Tynker Copilot, Kodable's "AI STEM tutor", Matific's "AI Assistant" or CodeCombat HackStack can be disabled by a school was not stated on any page opened.
- Khanmigo's underlying model provider is not named on the pages opened (Khanmigo Lite is "powered by OpenAI's custom GPTs" — see section 5 — but that is a separate product).
- Mathspace's help page says Milo "may get things wrong" and does not state whether Milo can reveal a full worked answer.

## 3. Skill map, standards alignment and grade coverage

### Takeaway
For an Indian school the alignments that exist in vendor documents are: IXL India (LKG–Class XII, "correspond to the Indian national curriculum", published skill lists per class), Khan Academy (NCERT-mapped Hindi and English courses for Indian classes), Mindspark (Grades 1–10, CBSE/ICSE/IGCSE), Countingwell (Grades 6–8 CBSE), Mathspace (India among its eight curriculum regions), Prodigy (claims Indian curricula, Grades 1–8) and Matific (Tamil Nadu government rollout, Classes 1–6). Eedi's 8,000-misconception map is the only openly licensed skill artefact (CC BY 4.0). Coding platforms align to CSTA (Tynker, Kodable, CodeCombat) rather than to any Indian framework; K-5-only products (Kodable, SplashLearn, Synthesis Tutor ages 5–11, DreamBox K-8 with evidence K-5) leave Grades 6–8 uncovered.

### Cited Findings

## 4. Independent efficacy evidence

### Takeaway
Independent randomised evidence exists for Mindspark (AER 2019 lottery study in urban India: +0.37σ maths in 4.5 months, middle-school grades — the only India RCT among the candidates), Zearn (RAND RCT, grades 3–5, +0.11 SD MAP, +0.07 SD STAAR n.s.), IXL (cluster RCT, grades 3–5, 0.13 SD Star Math), DreamBox (two RCTs, +0.10 average, K-5 only), ST Math (RCT, 10,860 students, WWC "meets standards with reservations") and Eedi (two-year RCT, Years 7–8, d = 0.30 at 24 months, evaluator WhatWorked Education). Khan Academy's evidence is large but internal and quasi-experimental; Prodigy's Johns Hopkins study is correlational; Matific's headline "34%" comes from a vendor-sponsored case study whose author says causation cannot be claimed; Synthesis, Math Academy, SplashLearn, Cuemath, Bhanzu and every coding platform have no independent trial found.

### Inferences
- Effect sizes for the well-evidenced maths platforms cluster around 0.1 SD per year in US settings (Zearn, IXL, DreamBox), with Mindspark's Indian result (0.37σ in 4.5 months, after-school centre model with a paid instructor present) the outlier — but it was an after-school centre programme, not in-school tablet use, so transfer to Cornerstone's model is uncertain.
- Eedi's evidence is unusual for its duration (24 months) and its independent evaluator; note the sample shrank from ~3,450 to 1,192 pupils, so attrition is a caveat.
- Khan Academy's numbers (0.26–0.36 SD) are dosage-conditional associations from the vendor's own team; treat as suggestive, not causal.
- Nothing in the coding market is evidence-based at the level a maths buyer would expect; the choice there must rest on data-return, privacy and curriculum fit.

### Inferences
- Cornerstone's "names stay in pii" rule is satisfiable out of the box on Code.org, CodeCombat, CodeMonkey, Matific and Prodigy (child_id as first name / username), and probably on IXL and Khan Academy via teacher-created usernames — but IXL's and Khan's children's policies were not readable, so this must be confirmed contractually. DreamBox (DOB required) and Synthesis Teams fail the rule; Scratch requires birthdate and gender, which the school could enter as constants only by misrepresenting data.
- Hosting is US (Code.org, Mathspace, DreamBox, CodeCombat, SplashLearn, Scratch) or unstated; Mindspark's policy permits transfer "outside India". None addresses DPDP; a DPA naming DPDP obligations would have to be negotiated with every vendor.
- Two Common Sense "sold or rented" findings (Tynker, Kodable) most likely concern adult/marketing data, but the brief's standard is the vendor's published terms, and those terms are the problem.

### Gaps
- Khan Academy's full privacy policy and IXL's children's privacy policy render only via JavaScript and could not be read; hosting location and username-only account creation for both are unverified.
- Common Sense evaluations for IXL, Scratch, Code.org, Matific, DreamBox and Mathspace either 404'd or overflowed; the search-listing summaries (IXL "may sell data from school or parent users"; Scratch "Warning"; Code.org "Pass"; Matific "may be used to customize targeted advertisements ... on other sites") are unverified.

- Math Academy, Cuemath, Bhanzu, Codingal privacy policies were not opened (404 or not located).
- No vendor page opened mentions India's DPDP Act 2023 or the DPDP Rules 2025.

### Shortlist — Mathematics

1. **IXL** — the only vendor whose per-skill export (CSV from any report, SmartScore per skill) is available without a district-scale contract, whose skills are already organised by Indian class (LKG–XII) with public skill lists for a crosswalk, whose product has an independent cluster RCT, and which carries no student-facing generative AI. Conditions before purchase: (a) written confirmation that classroom/school licences include report CSV export and that student accounts can be created with usernames only (child_id) and no date of birth; (b) the school price in INR; (c) a DPA that names DPDP obligations and hosting location.
2. **Khan Academy** — free, NCERT-mapped in English and Hindi, with the best-documented skill export in the market (mastery level, points, time, standards code per skill) — but that export is a Districts feature with a 250-licence minimum and Clever/ClassLink rostering, and Khanmigo for students is US-only. Shortlisted as (a) the free practice layer for Grades 4–8 today, and (b) a Districts enquiry to learn whether Khan Academy will sell the Districts tier (without Khanmigo) to an Indian school at or below 250 licences. Without Districts, results flow back only by teacher transcription.
3. **Mindspark (Educational Initiatives)** — the only candidate with an Indian RCT, Indian curriculum alignment for every grade the school will run, and an Indian data controller. Its weakness is the decisive criterion: no export or API is documented anywhere public. Shortlisted conditionally: EI must contract to deliver a periodic per-child, per-topic export (CSV/SFTP) keyed by the school's child_id, accept pseudonymous rostering (its policy currently collects name, age, phone and email), and sign a DPDP-compliant DPA that fixes hosting in India.

Reserves: **Mathspace** (best AI controls and transparent price, US hosting, India curriculum; loses on export and evidence) and **Eedi** (best evidence and an open misconception map that could be mounted directly onto Cornerstone's misconception table; loses on export granularity and UK/US curricula). DreamBox is excluded by its name-and-DOB requirement; Zearn by US-only curriculum and unknown export fields; Prodigy by in-game marketing to children; Synthesis and Math Academy by having no school data path at consumer prices.

### Shortlist — Coding

1. **Code.org (CodeAI)** — free, pseudonymous by design (picture/secret-word logins), level-by-level CSV export, nonprofit US hosting with explicit no-training statements, and AI features that are geo-fenced to the US (so children in Pune see none). The school builds the crosswalk from course lessons/levels to its coding skills.
2. **CodeMonkey** — structured, auto-graded practice from Pre-K to Grade 8 with username-only accounts and a PRIVO COPPA safe-harbour certificate; Clever/SSO. Shortlisted conditionally: the school must obtain (a) a per-student CSV export (none documented) and (b) a per-student price; without (a) it cannot feed the record.
3. **Scratch and ScratchJr** — as the free creative complement, not as a data source: there is no progress data to export, and Scratch's policy requires birthdate and gender and permits AI training. Evidence for Scratch work must be recorded by the educator (project rubric entered into the school's own record).

Not shortlisted: Tynker (Common Sense finds personal information "sold or rented"; Copilot generates code; export unverified), CodeCombat (privacy "Warning" with many unknowns; pricing and export unverified), Kodable (K-5 only), Codingal/Tekie (tutoring or lab-class models with no standard data path).

### Integration pattern each shortlisted platform needs

- **IXL**: Roster by CSV upload with child_id as the username and no real names (IXL publishes roster-upload guides; confirm the required fields). Return path: a teacher/admin downloads the Skill Analysis or Skill Proficiency CSV on a schedule (no API exists) → an n8n flow (Ring D) hands the file to an engine importer (Ring C adapter for IXL) that maps IXL skill id → Cornerstone skill id through a seeded crosswalk table (Ring A) and writes append-only evidence rows with source = IXL, SmartScore and questions answered, honouring the three-signal rule as far as IXL's data allows (IXL exports scores, not blank/wrong/wrong-with-working — the record must mark IXL evidence as "score-only"). Optional: LTI 1.3 grade passback if the school ever runs an LTI platform; not needed for the record.
- **Khan Academy (Districts, if sold)**: Rostering requires Clever or ClassLink; ClassLink is used outside the US and would itself hold names — so the school would roster ClassLink with child_id display names only. Return path: the nightly "All Skills CSV" (skill name, mastery level, points, time, standards) downloaded by an admin → importer mapping Khan skill name + Common Core code → Cornerstone skill. Note Course Mastery does not sync to LMSs, so the CSV is the only per-skill path. If Districts is unavailable, the free tier's evidence enters by teacher entry only.
- **Mindspark**: No standard exists. The contract must specify the export (child_id, topic/unit id, attempts, accuracy, mastery state, date), format (CSV or JSON), cadence (weekly), transport (SFTP or signed URL) and hosting region. The school builds a Mindspark topic → Cornerstone skill crosswalk after EI supplies its topic list. Until EI signs, Mindspark is home-practice only.
- **Code.org**: Sections created by the teacher; children log in with pictures/secret words; display name = child_id. Return path: the "complete dataset with level-by-level details" CSV per section → importer mapping course/lesson/level → coding skill via a seeded crosswalk; a submitted project flagged as an "assessment opportunity" becomes an evidence row only after the educator marks it (Ring A "approve").
- **CodeMonkey**: Username-only accounts. Return path does not exist yet — write the per-student CSV export into the purchase order or do not buy.
- **Scratch/ScratchJr**: No integration; evidence is educator-entered against the school's coding skills.
