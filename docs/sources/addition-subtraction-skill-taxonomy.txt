                  ADDITION & SUBTRACTION
                             Assessment Skill Taxonomy
      A complete case-based framework for building diagnostic and Olympiad-style assessments


       Purpose. This document treats a skill as a distinct assessment case whenever a child can make a
       different kind of mistake. Therefore horizontal vs vertical presentation, unequal digit lengths, number
       order, place-value alignment, carry/borrow location, zeros, answer-size changes, and missing digits
       are all tracked explicitly.


Scope: whole-number addition and subtraction. The framework is not tied to a specific grade and scales from 1-digit
to N-digit numbers.

Recommended database rule: do not encode every possible combination as a separate hard-coded topic name. Store these
dimensions as tags, then generate or select question sets by combinations of tags. This prevents cases such as “3-digit + 1-digit,
horizontal, carry” from being accidentally omitted.
