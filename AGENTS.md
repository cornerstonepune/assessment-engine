# Instructions for AI coding agents

For agents that read AGENTS.md (Codex, Cursor, OpenCode and others). The rules are the same for every agent:

1. `CLAUDE.md` (and `.claude/CLAUDE.md` where it exists): this repository's own rules.
2. `.claude/athena/CLAUDE.md`: how work is scoped, proven and shipped here.
3. `.claude/athena/standards/`: the architecture, AI-agent, design and writing standards. Open the one your task needs.

Read 1 and 2 before changing anything. Where they name Claude-only tools (skills, hooks, plugins), follow their intent with the tools you have.
